# SwiftUI_CSVEditor-TabularData-Table-

A simple CSV editor in pure SwiftUI using Table and TabularData frameworks.

This repository shows how we can
- read, write, display CSV files. 
- Insert / delete / edit columns / rows
- sort columns / rows

For more details, please refer to my blog [SwiftUI: TabularData + Table = Handling Unknown Dynamic](https://medium.com/@itsuki.enjoy/swiftui-table-tabulardata-handling-unknown-dynamic-885dbb3deab0).
